# JavaScript state-machine reconstruction mission

## What is valuable

The ANSI parser and buffer, terminal dirty-state logic, editor tokenizer, controls, compositor camera math, packed scene layout, shader algorithms, and touch flow are strong JS-to-PS1 candidates.

> # SIREN WARNING
>
> Do not import a WebView shell, DOM, iframe registry, browser fetch protocol, local storage, JSON contract, CSS architecture, or JavaScript runtime. JavaScript is semantic evidence, not a dependency. Do not build compatibility abstractions for the browser membrane.

## Permitted work

Port pure state and algorithms nearly mechanically to PS1. Replace DOM and browser graphics with proven Android Canvas, managed graphics, touch, and lifecycle objects. Keep shader source as shader source.

## Proof gate

Replay identical VT corpora and compare every cell and mode. Compare compositor buffers and transforms numerically before visual device proof.

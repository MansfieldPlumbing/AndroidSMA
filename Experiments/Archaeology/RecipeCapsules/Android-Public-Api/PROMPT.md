# Android public API recipe mission

## What is valuable

These specimens record working public managed Android API sequences for USB AOA, BLE, sensors, battery, storage, connectivity, notifications, clipboard, audio, haptics, flashlight, and application surfaces.

> # SIREN WARNING
>
> These C# files are not build inputs, product source, namespaces to preserve, or permission to translate C# syntax into PowerShell-shaped C#. Do not compile them, generate C# from PS1, retain their class hierarchy, or descend into Binder, JNI, or device nodes because direct PS1 feels difficult.

## Permitted work

Choose one currently required capability. Identify the smallest public API sequence and write a fresh PS1 experiment using the live Activity or application context.

## Proof gate

Record permission behavior, lifecycle, success, expected failure, and cleanup on a physical device. No promotion until an unlike consumer uses the PS1 result.

# High-value wheel lift

Approach these capsules with no assumption that anything must be reused.

The assignment is not to port, modernize, clean up, compile, reorganize, or
resurrect the legacy system. The assignment is to identify behavior that remains
independently valuable to AndroidSMA or DirectPortSMA and lift only that wheel
into a fresh, current experiment.

Read the capsule's `PROMPT.md` before reading its source.

## Required method

1. Name one observable behavior that might still matter.
2. Read only the smallest specimen needed to understand that behavior.
3. State what is algorithm/state and what is merely the old platform, process,
   browser, protocol, module, namespace, or application membrane.
4. Decide explicitly whether the wheel belongs to AndroidSMA, DirectPortSMA,
   both through independent implementations, or neither.
5. Write a fresh PS1, PSD1, shader, or deliberately isolated native experiment
   in the receiving project's present vocabulary.
6. Create parity tests from retained vectors or observable behavior.
7. Stop after the wheel passes or fails. Do not widen the mission.

## Absolute prohibitions

- Do not compile copied C#.
- Do not translate copied C# into generated or embedded C#.
- Do not preserve old namespaces, registries, hosts, modules, servers, or
  capability hierarchies without an independently demonstrated need.
- Do not import JSON as a product contract.
- Do not restore ADB as the Android research wire.
- Do not descend beneath a public .NET/Android API until that API has been
  exercised correctly and has produced a reproducible failure.
- Do not promote copied files or whole capsule directories into `src`.
- Do not mistake existing code, complexity, or effort already spent for proof
  that a wheel still belongs.

## Required result

Return a terse report containing:

- source specimens read;
- wheel identified;
- rejected historical assumptions;
- fresh experiment path;
- parity proof and result;
- remaining uncertainty;
- promotion recommendation: `NO`, unless an unlike consumer already exists.

Leaving a capsule with no extracted implementation is a successful result when
no wheel survives these tests.

# Cmdlet behavior reconstruction mission

## What is valuable

These specimens inventory parameter contracts, output shapes, errors, admitted operations, and useful command vocabulary.

> # SIREN WARNING
>
> These are not assemblies to include or C# to launder through generated source. Do not preserve PSCmdlet inheritance, attributes, namespaces, command families, or optional Microsoft command assemblies merely because they exist.

## Permitted work

Select one command demanded by a real workflow. Write a plain PS1 implementation using public APIs and typed PowerShell output. Keep it experimental until unlike consumers prove it deserves source.

## Proof gate

Prove admitted parameter, error, and output behavior, physical-device behavior where relevant, absence of optional command assemblies, and build-time lowering before promotion.
